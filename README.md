# SmartTimetable Pro

## Intelligent Automated School Timetable Generation & Management System

SmartTimetable Pro is a school timetable management and automated timetable
generation system being developed for Queen of Apostles Seminary Senior School.

The system is designed to manage:

- Teachers
- Subjects
- Classes and streams
- Rooms
- Lessons
- Teacher assignments
- Timetable periods
- Scheduling constraints
- Timetable generation
- Timetable validation
- Timetable publishing
- Timetable management

## Development Method

The project uses a hybrid incremental development methodology.

Each module is developed, tested, reviewed and integrated incrementally.
Previously developed modules may be revisited when new requirements,
constraints or architectural changes are identified.
